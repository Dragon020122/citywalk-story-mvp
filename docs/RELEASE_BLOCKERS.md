# 正式发布阻塞项

当前 MVP 使用 Mock POI 开发。以下事项全部完成前，不得切换为正式内容或用于真实线下导航：

- [ ] 完成两个路线包的正式 POI 人工核验。
- [ ] 确认每个正式 POI 的经纬度和地址。
- [ ] 使用腾讯地图完成路线校准。
- [ ] 确认地点开放性与公共访问条件。
- [ ] 确认每项任务可在现场安全执行。
- [ ] 验证每个 POI 的备用节点及切换路线。
- [ ] 至少完成一次端到端完整实地走测。
- [ ] 完成安全风险复核并处理所有阻塞问题。

完成后仍需运行 `APP_CONTENT_MODE=verified npm run content:validate` 和 `npm run check`，且不得以 Mock 数据补足正式 POI 数量。
