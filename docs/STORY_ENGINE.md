# 剧情引擎

## 目标

剧情引擎负责把经过策展的 POI、路线包与内容模板组织为可交互体验。

## 当前阶段

第十阶段已实现互动剧情执行引擎：

- XState 顶层状态覆盖开始、导航、到达、阅读、任务、选择、节点完成、改线、暂停、结局、完成、放弃和错误回退。
- 所有运行时转换由显式事件触发；任务、选择和节点奖励均按 ID 幂等处理。
- `packages/shared/src/story-runtime.ts` 提供 Story Graph 纯函数解释器和运行时 Zod Schema。
- 浏览器按故事 ID 保存经过校验的状态、上下文与暂停恢复点，刷新或返回页面不会重复发放副作用。
- 谜题仅支持单选、多选、顺序排列和现场观察码，不进行开放式 AI 实时判题。
- 支线入口通过 `requiredState` 和 ChoiceEffect 明确控制，拒绝或失败均可沿 `fallbackNext` 回到主线。

## 安全边界

AI 输出不能创建或替代正式 POI；进入产品的数据必须可追溯并通过共享 Schema 校验。
